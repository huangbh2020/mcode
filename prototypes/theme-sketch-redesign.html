手绘风主题 · 设计稿

立场:手绘是「风格」维度,不是「明暗」维度。与现有 ui.theme(system/light/dark)正交,落地为 settings key ui.themeStyle = "classic" | "sketch";渲染端在 <html> 上同时维护 .dark 与 .sketch 两个 class, 主进程 nativeTheme 完全不感知手绘。本稿给出四种形态:纸面手绘(一期目标)/ 牛皮纸(手绘的深色版,二期)/ 经典浅色 / 经典深色(现状对照)。

三条设计红线:① 代码、终端、diff 保持等宽字体不手绘(可读性优先,"手绘 chrome + 清晰数据流");② 位移滤镜只挂小尺寸 svg 图标, 绝不挂根节点 / 滚动容器 / 动画元素;③ 手写字体下 UI 基准字号需上调一档(14 → 15px),否则 11–13px 元信息发虚。

字体经 CDN 加载霞鹜文楷,离线自动回退系统楷体;后两项仅手绘形态生效
