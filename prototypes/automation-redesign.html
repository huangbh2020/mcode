设计要点(评审)

展示隔离
每次运行 = 一个 kind='automation' 的会话,不进左栏 / 搜索 / 置顶 / 手机列表;高频任务再密也不会污染常规会话流,统一在本页查看。
执行方式
到点由主进程直接创建会话并发送 prompt(复用编排器 worker 的链路),应用必须处于运行状态。
权限与通知
默认「接受编辑」;遇到仍需审批的操作照常挂起并发 OS 通知。窗口失焦时的回合完成/错误通知同样生效。
错过补偿
应用未运行时错过的触发点直接跳过,按规则算下一个;一次性任务过期后自动停用。
保留策略
每任务保留最近 N 条(默认 20),旧运行连同消息删除;运行中/等待审批的不清理。
重叠保护
上一次运行还在跑或等审批时,本轮触发自动跳过(照常推进下一次时间),避免并发堆积。
