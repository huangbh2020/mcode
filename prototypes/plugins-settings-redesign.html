设计说明

  1. 市场常驻右列(核心修复):已安装与插件市场各自独立滚动,互不推挤;装再多插件,市场也在原位。右列固定 392px,左列自适应。
  2. 行密度:插件行由约 3 行压缩为 2 行 —— 组件计数徽章内嵌到名称行;启用态由「monogram 底色 + 开关」表达,去掉长文案「已启用」徽标。详情仍是展开式,展开区保留来源 / 安装时间 / 三引擎矩阵 / 路径 / 组件清单。
  3. 安装入口收敛:常驻的 git 输入行 + 「本地目录」「zip 包」两按钮 → 收进「安装 ▾」菜单,选「从 Git 安装」才在工具行下方展开内联表单;降低常态视觉噪音。
  4. 搜索与过滤:搜索框常驻(按名称 / 描述 / 组件匹配);「全部 / 已启用」分段过滤兼作计数展示。
  5. 市场列内部:每个市场是一张分组卡(git / 本地目录徽标 + 数量 + 悬停刷新/移除),条目两行(名称+版本 / 一句描述) + 右侧「安装」;含 hooks 的条目加琥珀色标签,安装前即预警。「添加插件市场」虚线按钮按需展开表单。
  6. 方案二(顶部页签):改动最小 —— 页头放「已安装 / 插件市场」分段页签,正文整体切换。市场不再被推走,但仍需一次点击才能看到;适合不想引入双栏时的保守选项。
  7. 视觉完全继承应用现有 token(翡翠 accent、zinc 中性色、卡片 + hairline);切换右上「◐」查看深色。落地时需新增少量 i18n 字符串(搜索占位、过滤项、安装菜单项、市场条目标签等)。
