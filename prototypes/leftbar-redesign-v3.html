🧬 T3 Code 源码对照

  • 行内状态标签替代 spinner/未读徽章:◌ 运行中(天蓝+时长) / 待审批(琥珀) / 等待输入(靛蓝) / 失败(红) / ✓ 完成(绿,未读时);颜色是全系统约定
  • 收件箱模型:运行中的行整体淡出——"working threads aren't your problem yet", prominence 留给需要人的行(待审批/完成未读/失败)
  • 三行富卡片:① 项目 favicon+项目名 ② 标题 ③ 分支(「Always the branch——行最稳定的标识」)+ 终端/PR/diff/provider
  • 平铺 + 项目过滤:不再按项目建树;每张卡自带项目身份行,顶部「全部项目 ▾」下拉切范围(下拉内可搜索项目)
  • 置顶 = 卡片 + hairline 分隔线,可拖拽排序;归档 = Settled shelf(收起、灰度头像、hover 恢复)
  • 双击行内重命名;T3 原版为内联搜索输入框(未采纳——Mcode 已有 ⌘K 全局搜索,快捷入口区整块保留现状);默认宽 256px

🔀 Mcode 概念映射

  • 快捷入口区不动:新建会话(⌘N)/ 搜索(⌘K)/ 连接手机 三行维持现状样式与位置,只在其下加项目过滤行
  • 项目 favicon → 项目色块头像(Mcode 无 favicon,取名称哈希色+首字母)
  • worktree → 行内 fork + mcode/* 分支名(T3 正是行属性而非容器);同树多会话各自成行;原泳道的合并回/在此新建/重命名/移除 → worktree 行右键菜单(试右键带分支的行)
  • 未合并 → 分支旁 琥珀点+「未合并」(对应 T3 的 PR 徽标位)
  • provider → 行尾小色点(Claude 橙 / Pi 紫)
  • Settled shelf → 归档 shelf(Mcode 无 snooze/settle 生命周期,归档即终点,语义不变)
  • 项目分组「工作」→ 进过滤下拉的分组项;项目树/泳道/时间分组标签全部退场
这是方向性变化:从「项目树」转为「会话流」——项目退居过滤器和卡片身份行。worktree 泳道、树线缩进、时间分组都不再存在。若认可此方向,实施时 store 需加行内状态推导(运行时长/待审批/失败),归档改 shelf;搜索与项目过滤为增量能力。
