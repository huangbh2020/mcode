关键改动 · ① tab 无独立 chip 边框,共享轨道底色;② 激活态 bg=page 色,像「凸进」内容区;③ 1px 分隔线在轨道内部,不破坏连续感;④ 组标题只剩 图标 + 数字徽章,不再用「编辑区」字眼。

从「孤立 chip」到「单轨条」的视觉变化

  • 删除:每个 tab 的独立 border / border-radius / ring、组之间的浮动竖线、组标题的「会话/编辑区」文字。
  • 新增:
    • .track —— 一条共享容器,带统一 bg / border / border-radius / padding;
    • .tab 全部透明底 + 同 padding,只通过「bg = page 色」区分激活;
    • .gsep —— 1px 内置分隔线,在轨道的 bg 之上;
    • 激活 tab 顶部 1.5px accent 短线 —— 二级「当前位置」线索,对应 Chrome 标签的底部色条;
    • 组标题只剩「类型图标 + 数字徽章」,无文字。徽章本身就是「还有几个」的答案。
形状分化(药丸 vs 方片)已经被「会话头像(色块)/ 文件图标(线条)」取代 —— 这正是浏览器 favicon 的语义。一致性更高,也不需要为「窄屏保留形状」做基底样式声明。

为什么可以去掉「编辑区」三个字

原版用文字「会话 / 编辑区」做语义区分,但编辑区是有信息量补的：它隐含「文件是项目作用域」。 这件事被组标题旁边的数字徽章抢了：徽章里是 4,意味着「当前项目有 4 个文件」—— 作用域由项目切换、不是由文字承担。

所以现在两个组标题形态完全对称:图标 + 数字。文件组的图标(folder)告诉你「这是文件」,数字告诉你「有几个」。不再需要文字「编辑区」做补充。

会话组的图标(spark/msg)与左栏会话卡的头像同源,文件组的图标(folder)与右栏资源管理器同源 —— 组标题充当了「跨面板锚点」。

激活的两个改动

SdkMessageAdapter.ts 激活态: bg = page 色 + 顶部 1.5px 短线。视觉上像「被选中凸起」。
RuntimeManager.ts 空指针 锚点态: 描边 + 加粗,无填充 —— 表示「我从这条会话来,但视图不在它上面」。

两条区分从「填充 vs 描边」改成「bg 跳到 page 色 vs 描边」—— 第一个比原来更醒目,第二个保持原样。窄屏下当前会话的标题仍然要保留(它只让位成色点的是其他会话),所以「锚点态」在极窄时就是「唯一带标题的会话」,不需要任何特殊样式仍能一眼认出。

窄宽度阶梯 · 结构不变,只动 tab 宽度与会话头像

组标题已经是最小形态(无文字档),所以窄宽度让位比上一版更轻:只需要动 tab 的 max-w 与会话头像→色点。 文件永不折叠这条仍然成立,任何宽度下都看得见文件名(只是截断到 96px)。

一并要做的修正 & 落地顺序

① 单轨条要写进基底类,不设宽度条件

视觉变化只在 SortableSessionTab / SortableFileTab 基底样式上做(共享轨道、共享 bg、激活态 bg=page 色),与后续窄宽度降级完全独立。形状(药丸/方片)与按高度区分激活态这两件事都不再需要,统一交给轨道的「凸进」机制。

② 组标题图标与左/右栏同源

会话组用 i-msg(与左栏会话卡同源语义),文件组用 i-folder(与右栏资源管理器同源)。这样三个面板之间形成跨面板锚点 —— 即使 tab 条被挤到极窄只剩数字徽章,数字旁的图标仍是「这一片是什么」的可识别线索。

③ 锚点态的视觉锐度

激活态从「填充 + 顶线」改为「bg 跳到 page 色 + 顶线」,在共享轨道里更醒目。锚点态保留原样(描边 + 加粗),仍是无填充 —— 两条状态在视觉上完全分离:一个是「凸进」,一个是「画框」。

④ 极窄时 × 的去留

极窄(< 440px)把非激活 tab 的 × 收掉(完全无 hover 的窄空间里 × 会变成视觉噪声);激活 tab 的 × 仍保留 —— 它是当前正在看的标签的「关掉」入口,刚需。关闭语义仍走 tooltip。

⑤ 1px 分隔线在轨道内

把 .gsep 放在 .track 内部而不是在两个组之间另开 div —— 视觉上分隔线与轨道共享同一段 bg,「整条 strip 是一片」的语义被保住。这与上一版用 1px 发丝线 + 大留白的区别在于:前者是一段轨道里两个区,后者是两条轨道拼起来。

⑥ 溢出菜单与多行的可读性

共享轨道后,多行模式现在每个 tab 是 min-w-[170px] flex-1 —— 与激活态的「bg=page 色」配合,多行里哪一行的哪个 tab 凸进,余光就能看到。不会像孤立 chip 那样多行里全是一团圆角方块。

落地顺序
① 改基底样式:在 SortableSessionTab 与 SortableFileTab 上统一改为「无 chip 边框 / 共享轨道底色 / 激活态 bg=page 色」,删除两版各自的 border / ring / rounded-md/px-2.5/py-1 修饰。组标题重构为「图标 + 数字徽章」,删除「会话/编辑区」字眼。
② 改结构:UnifiedTabsBar 增加 .track 共享容器把 .send + .gsep + .fend 包住;1px 分隔线改为轨道内置的 .gsep。
③ 改激活态语义:.tab.on 的激活态样式改为「bg=page/chrome 色 + 顶线 1.5px」;锚点态沿用描边 + 加粗。
④ 改窄宽度降级:styles.css 中 @container tabbar 段从上一版的 L/M/S/XS 四段简化为三段(740/580/440),让位步骤从九条降到六条。
⑤ 补交互:右缘渐隐、滚轮转发(仍只作用于文件端)、极窄档 × 收掉、⋯ 溢出菜单按组分节。
⑥ 补词条:组标题不再有 i18n 字符串(只有图标 + 数字),关闭语义 tooltip 补进 i18n/zh|en/chat-stream.ts。
